ScheduleStream is a framework for planning & scheduling with continuous sampling operations motivated by the application of multi-arm robot Task and Motion Planning (TAMP). See the following ICRA 2026 paper for motivation & background, a tutorial on the ScheduleStream planning language, and a description of several ScheduleStream algorithms.
ScheduleStream is domain independent and thus both supports different robotics backends and can even be applied to applications beyond robotics. The currently supported applications are:
- cuStream: TAMP w/ cuRobo
- IsaacLab: TAMP automated demonstration generation
- cuMotion: TAMP w/ cuMotion
- Trimesh 2D: TAMP in a 2D plane w/ trimesh
- Blocksworld: Discrete sequential and temporal planning in blocksworld

Minimal installation instructions:
$ git clone git@github.com:NVlabs/ScheduleStream.git
$ cd ScheduleStream
ScheduleStream$ pip install -e .
Follow the instructions per application to install application-specific dependencies
