## SLIDE 10: OPTIMIZATION 2 - Vectorize the Loop

```
╔══════════════════════════════════════════════════════════════════╗
║  OPTIMIZATION 2: REPLACE LOOP WITH PARALLEL TENSOR OPS           ║
╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║   BEFORE: Sequential Loop                                        ║
║   ┌────────────────────────────────────────────────────────────┐║
║   │  FOR i = 1 TO 3136:                                        │║
║   │      diff = x[:,i] - μ[:,i]                                │║
║   │      tmp = Σ⁻¹[:,:,i] @ diff                               │║
║   │      d[i] = √(diff · tmp)                                  │║
║   │  END FOR                                                   │║
║   └────────────────────────────────────────────────────────────┘║
║                                                                  ║
║   AFTER: Single Tensor Operation (Einstein Summation)            ║
║   ┌────────────────────────────────────────────────────────────┐║
║   │                                                            │║
║   │   diff = X - μ                          [B, 100, 3136]     │║
║   │                                                            │║
║   │   tmp = einsum('cdi,bdi→bci', Σ⁻¹, diff)    ALL AT ONCE   │║
║   │                                                            │║
║   │   d² = einsum('bci,bci→bi', diff, tmp)      ALL AT ONCE   │║
║   │                                                            │║
║   │   d = √(d²)                                                │║
║   │                                                            │║
║   └────────────────────────────────────────────────────────────┘║
║                                                                  ║
║   TIME: ████████                                   80 ms        ║
║         ████                                       36 ms   2×   ║
║                                                                  ║
╚══════════════════════════════════════════════════════════════════╝
```
