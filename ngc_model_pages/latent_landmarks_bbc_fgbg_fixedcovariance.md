# Unsupervised Latent Landmarks BBC Fixed Covariance
Source: https://catalog.ngc.nvidia.com/orgs/nvidia/models/latent_landmarks_bbc_fgbg_fixedcovariance

## Model Name
"Unsupervised Latent Landmarks BBC Fixed Covariance"

## Description/Overview
"Unsupervised Disentanglement of Pose, Appearance and Background from Images and Videos"

This checkpoint provides a pretrained model on the BBCPose dataset for learning unsupervised landmarks from video data using a foreground-background factorized image reconstruction.

## Use Case
Learning unsupervised landmarks from video data with separation of pose, appearance, and background elements.

## Authors
Aysegul Dundar, Kevin J. Shih, Animesh Garg, Robert Pottorf, Andrew Tao, Bryan Catanzaro

## Training Data
BBCPose dataset

## Technical Details
The model uses foreground-background factorized image reconstruction for unsupervised landmark learning.
