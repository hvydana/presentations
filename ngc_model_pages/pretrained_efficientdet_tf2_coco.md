# Pre-trained EfficientDet Model trained on COCO
Source: https://catalog.ngc.nvidia.com/orgs/nvidia/teams/tao/models/pretrained_efficientdet_tf2_coco

## Model Name
**Pre-trained EfficientDet Model trained on COCO** (efficientdet-d0_trainable_v1.0)

## Description/Overview
This is a pre-trained EfficientDet model designed for object detection. The model card states: *"This model card contains pre-trained weights for the backbones that may be used as a starting point with the EfficientDet object detection networks in Train Adapt Optimize (TAO) Toolkit to facilitate transfer learning."*

## Use Case
Object detection applications including: smart cities, retail, healthcare, industrial inspection, and video analytics. The model performs *"object detection will recognize the individual objects in an image and places bounding boxes around the object."*

## Model Architecture
**EfficientDet-D0** architecture. The model is compatible exclusively with NVIDIA's TAO Toolkit.

## Input/Output Format
The model expects *"data in COCO format."* No specific technical input/output specifications are provided in the documentation.

## Training Data
The model was trained on **ImageNet1K and COCO dataset** with 80 object categories.

## Intended Users
Developers using NVIDIA TAO Toolkit for transfer learning and custom model development.
