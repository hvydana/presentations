# PeopleNet Transformer v2.0
Source: https://catalog.ngc.nvidia.com/orgs/nvidia/teams/tao/models/peoplenet_transformer_v2

## Description/Overview
"3 class object detection network to detect people in an image." The model detects persons, bags, and faces within images and returns bounding boxes and category labels for each detected object.

## Use Case
The primary intention is detecting people in RGB images from photos and videos. Secondary applications include detecting bags and faces, though these classes have lower accuracy. The model is designed for convenience-store retail analytics and other video analytics applications.

## Model Architecture
"This model is based on the DINO object detector with FAN-Small as a feature extractor." The architecture uses attention modules that attend to key sampling points around a reference to optimize training and inference speed.

## Input/Output Format

**Input:** B X 3 X 544 X 960 (B C H W)

**Output:** "Category labels (people) and bounding-box coordinates for each detected person in the input image."

## Training Data

**Pretraining:** A subset of the OpenImages dataset (~800K images), with pseudo-labels generated by a DINO detector trained on COCO classes.

**Fine-tuning:** "A proprietary dataset with more than 1.5 million images and more than 27 million objects for the person class." Dataset composition:
- Natural images: 1,444,335 images
- Simulated images: 27,417 images
- Approximately 50% from indoor office environments

## Intended Users
Developers using NVIDIA hardware and software who need object detection capabilities for video analytics, retail applications, or surveillance systems.

**For TAO Deployment:**
Use the trainable_v1.0 version with the provided experiment spec template. Configuration includes backbone (fan_small), 6 encoder/decoder layers, 900 queries, and 2048 dimension feedforward.

**For DeepStream Deployment:**
Download DeepStream SDK 6.1+, use configuration file `pgie_ddetr_tao_config.txt` and label file `ddetr_labels.txt` from the NVIDIA-AI-IOT repository, then run the deepstream-app with appropriate configuration.
