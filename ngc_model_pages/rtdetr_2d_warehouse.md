# RT-DETR 2D Warehouse
Source: https://catalog.ngc.nvidia.com/orgs/nvidia/teams/tao/models/rtdetr_2d_warehouse

## Description/Overview
The RT-DETR 2D Warehouse Perception Model v1.0 represents part of NVIDIA's RT-DETR family and incorporates an EfficientViT/L2 backbone. It has been pretrained on warehouse scene datasets to enable "precise 2D object detection in industrial environments" and is ready for commercial deployment.

The model detects seven warehouse-centric object classes: Person, Fourier_GR1_T2_Humanoid, Agility_Digit_Humanoid, Nova_Carter, Transporter, Forklift, and Pallet.

## Use Case
"Warehouse management personnel and logistics teams for 2D spatial object detection and tracking in AI-powered warehouse automation"

## Model Architecture
**Architecture Type:** Transformer

**Network Architecture:** RT-DETR with EfficientViT/L2 backbone

The model processes the final three stages of the EfficientViT backbone through an efficient hybrid encoder combining Transformer-based global context with CNN-style local spatial precision. It contains 2.7x10^8 parameters and is based on PeopleNet Transformer v2.0, fine-tuned from a pretrained base model.

## Input Format
- **Type:** Image (RGB)
- **Format:** Four-dimensional tensor with shape `[batch_size, 3, 544, 960]`
- **Parameters:** Batch size x 3 color channels x 544 pixels height x 960 pixels width

## Output Format
The model returns a dictionary with two primary tensors:

1. **Prediction Logits (`pred_logits`):** Shape `[1, batch_size, 300, 7]` containing "unnormalized prediction scores for each object query and class"

2. **Predicted Bounding Boxes (`pred_boxes`):** Shape `[1, batch_size, 300, 4]` providing "coordinates of the predicted bounding boxes for each object query"

## Training Data Used
The model was trained on 109K total images across six datasets:

- **AICity 2025:** 9K images from 2.9M synthetic data generated by NVIDIA IsaacSim
- **Cosmos AICity 2025:** 8K images from 2.7M processed AICity data
- **OpenImage V5:** 5K images (person class only) from 1.7M training images
- **Astro2.2:** 20K frames from proprietary indoor/outdoor camera footage
- **Warehouse Videos:** 38K highlight frames extracted from 48 public warehouse videos
- **Roboflow Forklift Dataset:** 29K images from 20 public datasets

## Intended Users
Warehouse management personnel and logistics teams utilizing AI-powered warehouse automation systems.
