## AMD Pin-to-Pin Replacement Priority (NVIDIA → AMD switching customers)

The 48 models below are the ones a customer running on NVIDIA **cannot simply carry over to AMD hardware** —
either the license grant is scoped to "systems with NVIDIA GPUs" (Model EULA), or the weights are
DRM-encrypted and require NVIDIA's own TAO/DeepStream/TensorRT toolchain to even load (TAO Purpose-Built).
These are the models AMD needs a pin-to-pin equivalent for. The other 49 GREEN-license models already run
wherever the customer wants — that's a ROCm/runtime compatibility problem, not a "build a replacement model"
problem — so they are not listed here.

### Tier 1 — highest priority (NVIDIA Metropolis/DeepStream perception stack, most commonly deployed in production)

| NVIDIA model | Function | Why it matters |
|---|---|---|
| TrafficCamNet | Vehicle detection (traffic cameras) | Core Metropolis/smart-city SKU |
| PeopleNet / PeopleNet-AMR | Person detection | Most widely deployed DeepStream model |
| License Plate Recognition (LPRNet) + LPDNet | Plate detection + recognition pair | Sold as a pair, tolling/parking/security |
| VehicleMakeNet / VehicleTypeNet | Vehicle attribute classification | Paired with TrafficCamNet in the same pipelines |
| ReIdentificationNet (+ Transformer variant) | Person re-identification across cameras | Retail/security analytics |
| PeopleSemSegNet / PeopleSemSegNet AMR | Person segmentation | Privacy-masking, robotics safety zones |
| Retail Object Detection / Retail Object Recognition | Shelf/product detection | Retail analytics vertical |
| Action Recognition Net | Action/behavior classification | Security, workplace safety |
| BodyPoseNet / PoseClassificationNet | Human pose estimation | Robotics, ergonomics, fitness |
| Optical Character Detection/Recognition (OCDNet/OCRNet) | Scene text OCR | Logistics, document/label reading |

### Takeaway

Tier 1 + Tier 2 (30 models) is the actual "customer has this running on NVIDIA today and can't move it" list
for a robotics/physical-AI buyer — that's where a pin-to-pin AMD model (or a ROCm-native equivalent with
matching input/output contract) has real switching-cost payoff. Tier 3/4 (18 models) matter only if AMD is
also chasing the biometric/kiosk or HPC-climate verticals specifically.
